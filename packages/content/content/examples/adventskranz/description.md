Based on [Fabian's polar-coordinate Adventskranz](https://snippets.qawsed.site/p5js/polar-coordinates-adventskranz/index.js), seven passes draw 360 marks each around one ring, for 2,520 branches in total. Each position comes from a degree angle and radius; independently randomized local endpoints create varied branch directions and lengths. OKLCH strokes preserve the original 40–100 lightness and 260–350 hue ranges. The original 400-pixel ring is compacted for the square canvas.
