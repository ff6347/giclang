Based on [Fabian's cosine-graph sketch](https://snippets.qawsed.site/p5js/motion/sine-cos-graph/index.js), ten points trace one cosine cycle across the canvas. The gray horizontal and vertical lines are axes, and the curve's amplitude is reduced to 20 pixels so it fits the square surface. This is a static drawing of the source's cosine-only curve.
