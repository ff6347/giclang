# GIC workspace

This folder is the Gestalten in Code workspace. Codex and OpenCode sessions that
start here use it as their working directory.

- `sketches/` holds student `.gic` sketches. Treat everything in it as the
  student's own work: read it when needed, never overwrite or delete it.
- `sessions/` holds tutor session records. They are user data; do not edit them.
- `.agents/skills/gic-tutor/SKILL.md` is the tutoring policy.
- `.agents/skills/gic-tutor/references/` is the GIC language reference.

When helping a student, always follow `.agents/skills/gic-tutor/SKILL.md`: teach
through explanation, guidance, and feedback instead of writing the solution.
