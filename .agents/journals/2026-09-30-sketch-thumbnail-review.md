# Sketch thumbnail review

- [fix] Prop-driven Monaco synchronization now suppresses its content-change callback. Document activation continues to schedule its own preview, while Save and Save As keep the exact accepted Canvas render and avoid rerunning randomized source merely because formatting changed the saved text.
- [evidence] A real Firefox PWA workflow opened Monaco, rendered randomized GIC through the worker and Canvas, used actual Save As and Save downloads, checked formatted downloaded source, asserted no additional worker after the debounce interval, and compared all Canvas pixels before and after both saves. The regression failed before the synchronization helper because it observed an additional worker; it passed after the fix. Same-source document-isolation and existing invalid-source preview tests also pass.
- [fix] PNG validation now calls `png` 0.18 `Reader::finish()` after decoding the frame, validating trailing chunks and IEND CRC. Production thumbnail saves reject both a missing final CRC and corrupted IEND CRC without changing exact source, description, or thumbnail bytes.
- [evidence] Transaction rollback regressions now exercise `sketch_bundle` production helpers with genuine 100 × 100 PNGs. A failure during the actual source/description/thumbnail install restores all three originals; a failed restore retains the thumbnail backup at the reported recovery path. Red testing without `Reader::finish()` accepted the truncated PNG and failed the real DocumentStore preservation assertion.
- [fix] Removed the test-only duplicate transaction implementation from `documents.rs`; rollback checks now cover production `replace_sketch_files`, backup, install, and rollback helpers.
- [evidence] Focused Firefox document/PNG tests passed 12/12. Full Firefox E2E passed 94 with 8 tutor tests intentionally skipped; the `be27ae0` hover case passed without retry. Captured `/tmp/feat-sketches-gallery-slice2-review-e2e.log` contains no React component-update warning text; prior review evidence attributes those warnings to pre-existing tracked `32ada2f` LayoutInternal updates during Menubar/TabSet rendering, and no unrelated layout change was made.
- [evidence] `pnpm test` (422 passed), `pnpm test:compact`, core/content/CLI typecheck, browser typecheck, lint, format check, browser build, native tests (153 passed, 1 ignored live test), Rust format, Clippy, and desktop build passed.
