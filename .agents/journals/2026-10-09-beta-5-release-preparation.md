# Beta.5 release preparation

- [scope] Fabian authorized a version-bump PR after Windows PR #101 was merged into `origin/main` at `521d5e8`. Preparation uses branch `release/v0.9.0-beta.5`; no main merge, signed macOS dispatch, tag, npm publication, or GitHub Release is authorized here.
- [decision] Set root, core, CLI, content, editor, desktop, the Rust crate, and the Tauri product to `0.9.0-beta.5`. Keep site at `0.0.1`, styles at `1.0.0`, and macOS short version at numeric `0.9.0`; increment the macOS build version from `0.9.3` to `0.9.4`.
- [technique] Use pinned pnpm version commands with automatic commits/tags disabled. Pnpm also checks worktree cleanliness in that mode, so the already inspected, agent-owned metadata changes use its no-git-checks option for the version operation only; normal commit hooks remain enabled. Offline Cargo metadata updates only the crate's own lock entry; no dependency versions or pnpm lockfile change.
- [verification] The release metadata diff contains exactly the established nine files and ten version-line replacements. Frozen pnpm installation, core/CLI and compact tests, package/browser typechecks, lint, root Prettier formatting, full macOS native tests (159 passed, one existing live-provider test ignored), Rust formatting/Clippy, desktop app/DMG packaging, and site build/typecheck pass. Built `GiC.app` has numeric short/build versions `0.9.0` and `0.9.4`. Site direct-eval and browser large-chunk advisories remain unchanged; no browser executable behavior changes, so browser E2E is not rerun for this metadata-only preparation.
- [decision] Keep the download page unchanged until beta.5 assets are public. After the version PR is merged and candidate builds are explicitly authorized, build macOS Apple Silicon, Linux amd64 AppImage/deb, and unsigned Windows x64 NSIS from one landed source revision, verify binaries and manifests, then publish them together. Do not reuse or relabel beta.4 artifacts.
- [risk] The signed/notarized macOS candidate workflow is manual and main-only; its PR probe is restricted to the beta.1 branch. Local unsigned macOS packaging does not prove Apple notarization or clean-machine acceptance. Windows and Linux PR builds validate beta.5 packaging but remain internal candidates, not release assets.
