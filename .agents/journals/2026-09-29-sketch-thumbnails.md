# Sketch thumbnails

- [decision] Slice 2 sends an optional base64-encoded PNG with the existing desktop Save and Save As content payload. The webview captures only when its current successful Canvas render is accepted for the exact source snapshot being saved; unavailable capture sends no replacement image.
- [decision] A document activation schedules a fresh preview even when its source text equals the prior document's text. Save As preserves the accepted source preview so copying a sketch does not rerun GIC merely to capture its thumbnail.
- [decision] Native persistence decodes and bounds the payload, validates a complete 100 × 100 PNG, then transactionally replaces only the source, description sidecar, and optional thumbnail in an owned sketch bundle. Missing capture excludes the thumbnail from the transaction and preserves the prior image; standalone sources still write source only.
- [evidence] Native integration was red before the save-with-thumbnail seam existed (missing method and PNG dependency). After adding real temporary-file save/Save As/preservation cases, `cargo test ... thumbnail_saves_replace_real_pngs_transactionally_and_save_as_copies_them` passed. Invalid PNG data is rejected before source or thumbnail replacement; an actual staged-file install failure restores source, description, and thumbnail backups.
- [evidence] The Firefox identical-source document-switch test was intentionally run red with document-activation preview scheduling disabled: the Canvas pixels did not change after opening the second document. It passed after activation invalidated the prior capture and started the new preview. `e2e/png-export.spec.ts` now checks same-source document isolation and native-size Canvas pixels through the shared capture helper.
- [evidence] `pnpm test`, `pnpm test:compact`, `pnpm typecheck`, `pnpm typecheck:browser`, `pnpm lint`, `pnpm fmt:check`, `pnpm build:browser`, `pnpm test:e2e`, `pnpm test:desktop`, Rust format, Clippy, and `pnpm build:desktop` passed. Full browser suite: 93 passed, 8 explicitly skipped tutor tests. Native suite: 153 passed, 1 ignored live-provider test. The browser build retains its existing large-chunk warning.
- [risk] `pnpm test:e2e` printed React “Cannot update a component while rendering a different component” console errors while rendering layout controls; tests passed, and these warnings were not investigated in this slice. The known `be27ae0` example-card hover case passed in the full run. No unrelated fix was made.
- [blocked] The macOS application and DMG build successfully, but the actual packaged WebKit/native-dialog Save/Save As flow remains unverified. Browser tests validate shared Canvas capture/freshness; real temporary-file tests validate native PNG persistence; neither substitutes for packaged Canvas-to-file pixel comparison and random no-rerun acceptance.
