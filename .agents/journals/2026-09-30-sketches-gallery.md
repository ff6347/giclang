# Sketches gallery

- [decision] Desktop Sketches is a separate FlexLayout application tab, included only in desktop workspace layouts; workspace schema version 11 adds it during migration and strips it from browser/PWA layouts.
- [decision] The native host discovers direct-child bundles only under the current workspace's `sketches/`, requires same-name `.gic` plus a regular `description.md`, and returns only opaque entry IDs, saved description text, and an optional validated PNG data URL. Opening an ID revalidates it against the current sketchbook before entering the existing pending-open/discard/activation lifecycle.
- [decision] Shared description codec validation filters malformed and disabled metadata and sorts enabled cards by order then title. User Markdown uses an isolated renderer with HTML disabled, inert links, and image sources omitted; bundled trusted Markdown compilation is not reused.
- [evidence] TDD: the Sketches visibility/sort fixture failed when the enabled filter was temporarily removed (`disabled` appeared first; `/tmp/gic-sketches-gallery-red.log`), then passed after restoration.
