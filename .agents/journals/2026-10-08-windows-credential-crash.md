# Windows credential crash

- [scope] Fabian authorized investigating and fixing the Windows native credential crash on the existing `feat/windows-build` branch and draft PR #101. Windows execution stays in GitHub Actions; no developer dependencies are needed on the Windows 10 test computer.
- [lesson] Dependency `windows-acl` 0.3.0 allocates a `Vec<u16>` for each copied SID but does not set its logical length. GIC cloned those zero-length vectors before native ACL removal, producing empty vectors whose pointers do not contain SID data. The removal callback passes that pointer to Windows `EqualSid`.
- [decision] Preserve ownership by moving each entry's SID vector through `into_iter()` into the synchronous removal loop. This is a two-line behavioral fix plus an explanatory comment; it adds no dependency, conversion, unsafe block, credential-format change, or permission-policy change.
- [technique] Three Windows-only regressions use actual temporary files and ACLs. An inheritable Everyone-read grant ensures inherited access must be removed; independent ACL inspection checks exactly one current-user grant, exact read/write rights, and zero inheritance flags. Tests also cover reopening, replacement, provider-isolated sign-out, final deletion, and rejection without rewriting when another principal is granted access.
