## Language and Analyzer Decisions

- [decision] The parser accepts `return` wherever a statement is syntactically valid. `ReturnStmt.keyword` retains the `return` token, and the analyzer reports `Cannot return outside a function.` at that token.
- [decision] Baseline required-return analysis accepts any explicit return in a function body or nested `if`/`repeat` block. Path-sensitive all-branches analysis is deferred to git-bug `a751ee3`.
- [decision] Function declarations retain optional `"void" | "value"` return-kind metadata alongside their token and arity. Missing and mixed functions leave the valid return kind absent to avoid cascading call diagnostics.
- [technique] A pure recursive pre-pass classifies statement trees as `"none" | "void" | "value" | "mixed"`. It merges `if` branches and recursively scans repeat bodies without walking return expressions or mutating scopes.
- [technique] Valid return metadata is attached before semantic body traversal so recursive calls can distinguish void and value-returning functions. The normal walk later analyzes return expressions exactly once.
- [decision] A direct call expression statement does not require a result. Calls used in initializers, operators, return values, or arguments do require values; the standalone exemption never propagates to argument expressions.
- [decision] At a call site, arity mismatch takes priority over void-value misuse so one callee token receives at most one primary diagnostic. Arguments are still traversed for independent diagnostics.

## Tests and Lessons

- Coverage includes explicit void/value returns, every missing-return function, nested returns, mixed kinds, outside-function returns, state reset between functions, standalone and value-required calls, recursive value and void calls, nested `if`/`repeat` recursive classification, argument contexts, and arity diagnostic priority.
- [lesson] Checking only direct function-body statements misses returns nested in conditionals and repeats. Return classification must recurse through statement containers.
- [lesson] A mutable Boolean or shared merge state permits contradictory states and leaks between functions. A pure four-state classifier makes every merge combination explicit.
- [lesson] Calculating return kind after walking a function body is too late for recursive calls. Classification must happen before body expressions are analyzed.
- [lesson] Computing a classifier result without assigning it to declaration metadata leaves recursive calls unchanged; pre-pass output must be connected to the symbol before traversal.
- [lesson] Independent arity and void-context checks produce duplicate diagnostics at one token. Diagnostic priority belongs in the call-resolution branch, while argument traversal remains unconditional.
