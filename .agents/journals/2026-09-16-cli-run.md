# Slice 5 CLI Run

## Completion

`gic run <file>` now reads source through the same file boundary as `gic check` and executes it through `runSource()`. Default stdout contains each retained `print` entry in execution order. Diagnostics remain on stderr, including after output emitted before a runtime failure.

`gic run <file> --commands` suppresses `print` output and emits the successful `Command[]` as one deterministic JSON line. It does not render an image or introduce renderer/export flags. `--commands` is valid only for `run`; missing or extra arguments and unsupported options retain usage status 64.

The stable usage and help text documents `check`, `run`, and the inspection mode. The installed-package process test packs, installs, and executes `gic run`.

## Verification

- [technique] Spawned process tests pin valid print output, print ordering, command JSON, parse/analysis/runtime diagnostics, output retained before runtime failure, missing files, invalid arguments/options, help, and installed package execution.
- [decision] `--commands` serializes commands only after successful execution. It is intentionally not an interleaved event stream with `print` output.
- [verification] `pnpm test`, `pnpm typecheck`, `pnpm lint`, and `pnpm fmt:check` pass.
- [risk] `pnpm test:compact` discovers an unrelated Electron spike test that fails before its test body because `@earendil-works/pi-agent-core` is not installed. Slice 5 CLI tests pass in that run.
- [resolution] `test:compact` now explicitly discovers the intended core and browser-local tests instead of unrelated self-contained spike tests; the compact suite passes.
