Adapted from the closely related [p5.js Random Circles](https://github.com/ff6347/gestalten-in-code/tree/e8b8f8446c13c01494ccfd1e92ce2bb1638daf66/chance/p5js/random_circles) and [Processing Random Circles](https://github.com/ff6347/gestalten-in-code/tree/e8b8f8446c13c01494ccfd1e92ce2bb1638daf66/chance/processing/random_circles), both created by **Fabian Morón Zirfas**.

Both originals express the same teaching idea with equivalent loop structure. This GIC adaptation follows the Processing version's opaque gray ground and outlined circles while using a seed to make the random size pattern reproducible.
