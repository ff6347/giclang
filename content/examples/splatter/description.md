Adapted from [Splatter](https://github.com/ff6347/gestalten-in-code/tree/e8b8f8446c13c01494ccfd1e92ce2bb1638daf66/repeat/p5js/splatter), created by [Fabian Morón Zirfas](http://fabianmoronzirfas.me).

One hundred tiny circles vary in size and gather within a narrow range around a randomly selected point. This static GIC adaptation uses `randomSeed(1326)` to make the chance-based composition deterministic.
