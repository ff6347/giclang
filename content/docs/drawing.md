### Points

A point is a single coordinate on the canvas. It is declared using the `point` keyword.

```gic
point(x, y);
```

### Lines

A line is a straight connection between two points. It is declared using the `line` keyword.

```gic
line(x1, y1, x2, y2);
```

### Circles

A circle is a circular shape. It is declared using the `circle` keyword.

```gic
circle(x, y, radius);
```

### Ellipses

An ellipse is a circular or oval shape. It is declared using the `ellipse` keyword.

```gic
ellipse(x, y, width, height);
```

### Rectangles

A rectangle is a rectangular shape. It is declared using the `rect` keyword.

```gic
rect(x, y, width, height);
```

### Quads

A quad is a quadrilateral shape. It is declared using the `quad` keyword.

```gic
quad(x1, y1, x2, y2, x3, y3, x4, y4);
```

### Triangles

A triangle is a triangular shape. It is declared using the `triangle` keyword.

```gic
triangle(x1, y1, x2, y2, x3, y3);
```

### Arc

An arc is a curved line segment. It is declared using the `arc` keyword.

```gic
arc(x, y, radius, startAngle, endAngle);
```
